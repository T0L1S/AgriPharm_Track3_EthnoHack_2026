# Sources and provenance

## Team-supplied files

The MédicAM workbook was provided by the team. Its producer is CNAM / Assurance Maladie, and its own readme states edition 2026-09-30. The forecast CSV was provided by Paterakis, Role B. The start month 2026-08 comes from his message, not from an explicit date in the CSV.

Official dataset description: [MédicAM — Assurance Maladie](https://www.assurance-maladie.ameli.fr/etudes-et-donnees/medicaments-classe-atc-medicam). The description page was checked on 2026-11-03. The team-supplied source file has not been replaced with a newer download.

Third-party source ownership and terms remain with their respective providers. This package does not assign a new licence to third-party files.
